## Featured Projects

### 1. Sales Lead Automation

**Business Challenge**

Manual lead intake, spreadsheet updates, and follow-up notifications can create delays, inconsistent data, and missed business opportunities.

**Solution**

An n8n workflow that automates lead intake, validation, Google Sheets integration, and email notifications, with additional mechanisms for error handling and recovery.

**Key Capabilities**
- Automated lead intake and data validation
- Google Sheets integration
- Email notifications
- Retry and recovery mechanisms
- Centralized error handling
- Execution status tracking

**Business Value**

Reduces repetitive administrative work, improves process consistency, and provides better visibility into workflow failures.

### 2. Northstar AI Customer Support Agent

**Business Challenge**

Customer support teams frequently handle repetitive questions about orders, delivery delays, and store policies. These requests often require information from multiple systems.

**Solution**

An AI-powered customer support workflow using n8n, a locally hosted language model, retrieval-augmented generation (RAG), and specialized tools.

**Key Capabilities**
- AI-powered customer conversations
- Knowledge retrieval through RAG
- Order lookup through Google Sheets
- Support ticket creation with customer confirmation
- Integration with Ollama and Qdrant
- Shared error handling and fallback behavior

**Business Value**

Demonstrates how AI agents can assist with routine customer inquiries while preserving human escalation for cases requiring additional review.

[View Project Details](projects/northstar-customer-support/README.md)
